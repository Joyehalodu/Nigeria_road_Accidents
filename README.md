# Nigerian Road Accident Analysis Report
## Project Overview
 This project analyzes road accident data across Nigeria with a focus on identifying the major causes of accidents, understanding patterns across states, and recommending actionable solutions to improve road safety.
 Road accidents remain a critical public safety issue in Nigeria, affecting lives, economic productivity, and national development. This analysis aims to provide data-driven insights to support better decision-making.

## Objectives
* Identify the leading causes of road accidents
* Compare accident causes across different states
* Analyze patterns over time
* Provide practical recommendations to reduce accidents

## Dataset Description
 The dataset contains aggregated accident records with the following key fields:

* State → Location of accident
* Time_Period → Quarter and year of occurrence
* Speed_Violation → Accidents caused by over-speeding
* Phone_Use_While_Driving → Driver distraction from phone use
* Tyre_Burst → Tyre-related failures
* Mechanical_Defect → Vehicle faults
* Brake_Failure → Brake system issues
* Overloading → Excess passengers/cargo
* Dangerous_Overtaking / Wrong_Overtaking → Risky overtaking
* Dangerous_Driving → Reckless driving behavior
* Bad_Road → Poor road conditions
* Route_Violation → Ignoring designated routes
* Obstruction / Spillage_On_Surface → Road hazards
* Driving_Against_Traffic → One-way violations
* Pedestrian_Wrong_Use → Pedestrian-related causes
* Fatigue → Driver tiredness
* Traffic_Light_Violation → Ignoring signals

## Methodology
The analysis was carried out using:

* Data cleaning and transformation in Excel
* Aggregation of accident counts by cause and state
* Exploratory Data Analysis (EDA)
* Visualization using dashboards (Excel)
