# Nigerian Road Accident Analysis Report
## Project Overview

* This project analyzes road accident data across Nigeria with a focus on identifying the major causes of accidents, understanding patterns across states, and recommending actionable solutions to improve road safety.
* Road accidents remain a critical public safety issue in Nigeria, affecting lives, economic productivity, and national development. This analysis aims to provide data-driven insights to support better decision-making.

** Objectives
* Identify the leading causes of road accidents
* Compare accident causes across different states
* Analyze patterns over time
* Provide practical recommendations to reduce accidents
